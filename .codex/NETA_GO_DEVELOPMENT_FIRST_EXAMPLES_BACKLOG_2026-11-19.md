## 2. Verified current surface and constraints

The repo currently has **two** user-facing executable examples:
- `examples/client/main.go`: flags `-addr` and `-system-id`, a Bind, one SendRequest/Completion, one SendNoWait event, Client.Stop.
- `examples/server/main.go`: `-listen` flag, permissive non-empty BindValidator, Request echo, one-way `event:` convention and Server.Stop.

Both are currently paired by `scripts/example-smoke.sh` and README commands. **Preserve those entry points and log-based smoke semantics**; adding examples must not break existing `go run ./examples/client` and `go run ./examples/server`.

`config.go`, `options.go`, `docs/CONFIGURATION.md` already expose typed ClientOption, ServerOption and SessionOption, including version, timeouts, worker pools, queue/retained budgets, reconnect and bounded callback panic diagnostics. Their defaults are valid; no mandatory custom config or runtime hot reload is needed. No production API change is justified merely to create a demo.

The feature branch has **13 changed production Go source files vs main**, including callback/diagnostics/Session/worker/ledger changes. This is unmerged, not evidence that the corresponding feature code has not been developed. The task ledger already marks QA-007 feature-branch implementation complete; QA-004 implementation/microbench complete with heavy P99 qualification OPEN; QA-005 qualification/retention evidence OPEN. P9-06 release is unauthorized.

**Examples rules:** Go stdlib only, no new library dependency, no external credentials or production-like authentication claims, no hidden infinite retry or transport replay, no automatic V2→V1 fallback, no change to wire framing. A Client `SendRequest` / `SendNoWait` successful return is local queue admission, not peer delivery ACK. Real Server BindValidator examples must clearly state demo-only policy. Use `WithClientSessionOptions` and `WithServerSessionOptions` for Session settings. Keep all samples bounded and shutdown-aware; show defaults as well as optional overrides.
