## Lifecycle and alias invariants for any later adapter

1. An admitted outgoing backing slice is one F1 or F4 allocation through construction, queue and Writer; transfer of responsibility is **not** a second allocation.
2. F2 and F3 actual Body backing must not be conflated with Header-inclusive resource credits; a callback after Done can keep storage owned until return/cancel.
3. Each pendingRequest, Worker Pool, Queue and backing array is counted once at a time; distinct references (Server map and Client registry, First/Recent/OnClose) are aliases, not extra memory.
4. Session identity and generation maps changing between ticks must invalidate the purported complete window. A *frozen* registry also affects GC liveness and its bias is currently unqualified.
5. A per-Session event HWM sum is not a simultaneous global maximum. An observed sampled zero is not physical zero. Every unsupported category must remain EXCLUDED/INCONCLUSIVE.
6. Exact same versioned effective adapter, source and fixture compatibility must be proved on both baseline and candidate; immutable historical SHA may not change.

## Development-complete vs Phase-Q blockers

**DEV implementation conclusion:** Existing V9 F1–F5, V10–V12 D1/Pending, V13–V16 Worker/Queue and V17/V18 generation tests already provide *honest named partial diagnostics*. No concrete **additional** owner-approved production hot-path or test-only byte-category implementation can be specified without falsely assigning unknown runtime/alias sizes or silently adding measurement overhead. Therefore stop creating V19+ adapters for incremental vanity coverage. DEV-02 is complete as a **bounded source/coverage classification**; it is **not** `MEM-004 DONE` and does not assert full M1/D1 implementation.

**Exact remaining blockers to canonical field, handled after Phase D:** F4 pre-Session entry/provenance, M1 Session/queue/charge/maps and D1 rendered string/record attribution coverage, early-retired generations and observer retained-reference effects, simultaneous per-run window sampling with accepted peak-gap/missed-event semantics, matched 10-pair implementation overhead, stable reference environment, 30-minute soak, owner approval for numerical baseline/SLA and gate. Where approved Scope B permits exclusions, their effect on metric validity must be reviewed; unknown must not quietly become `MEASURED=0`. If canonical field cannot be defended, Phase Q must return **INCONCLUSIVE** and request a narrow new owner decision rather than enabling a gate.
